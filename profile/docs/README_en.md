# Signify Indonesia

Signify is a web-based application that supports learning and translating Indonesian Sign Language (BISINDO) in real-time using AI.

## 🎯 Our Goals

This app aims to bridge communication gaps between the deaf community and the general public, while also promoting inclusivity awareness.

## 🚀 Our Solutions

We offer the following core features:
- **Sign Academy** — BISINDO learning modules for alphabets, and numbers.
- **Real-Time Translator** — An AI-powered system to detect and translate BISINDO gestures on the fly.
- **API Documentation** — Open API access for developers to build more inclusive applications.
