# Signify Indonesia

Signify adalah aplikasi web yang bertujuan untuk mendukung proses pembelajaran dan penerjemahan Bahasa Isyarat Indonesia (BISINDO) secara real-time menggunakan teknologi AI.

## 🎯 Tujuan Kami

Aplikasi ini dibuat untuk menjembatani komunikasi antara teman Tuli dan masyarakat umum, serta meningkatkan kesadaran akan pentingnya inklusivitas.

## 🚀 Solusi Kami

Kami menyediakan fitur utama berikut:
- **Akademi Isyarat** — Modul pembelajaran BISINDO berupa alfabet, dan angka.
- **Penerjemah Real-time** — Sistem berbasis AI untuk menerjemahkan gerakan tangan BISINDO secara langsung.
- **Dokumentasi API** — Akses terbuka bagi developer untuk mengembangkan lebih lanjut aplikasi inklusif.
